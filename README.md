# Style Spy
Steal the style. Save the system.

## Install
1. Unzip this folder.
2. Open chrome://extensions and turn on Developer mode.
3. Click "Load unpacked" and pick the style-spy folder.
4. Pin Style Spy, open any website and click the icon.

Tabs: Colours, Typography, Inspect, CSS. "Save as kit" stores everything in chrome.storage.local; "My kits" opens the dashboard.
